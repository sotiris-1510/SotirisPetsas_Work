
# HW4_Team50 - Υπολογισμός Σημασιολογικής Ομοιότητας Λέξεων

## Περιγραφή
Η εργασία υλοποιεί ένα σύστημα για την επίλυση ερωτήσεων τύπου TOEFL μέσω σημασιολογικών διανυσμάτων λέξεων.
Το πρόγραμμα:
- Εκπαιδεύεται σε κείμενα για να χτίσει σημασιολογικούς περιγραφείς (semantic descriptors).
- Υπολογίζει ομοιότητες μεταξύ λέξεων με βάση cosine similarity.
- Δίνει απαντήσεις σε ερωτήσεις εύρεσης συνώνυμου.
- Μετράει την ακρίβεια των απαντήσεων.

---

## Οδηγίες Compile και Run

### Βήμα 1: Compile

Από τον φάκελο `HW4-Team50`, εκτελέστε:

```bash
javac -d . HW4_Team50\*.java
```

---

### Βήμα 2: Εκτέλεση

Για να εκτελέσετε το πρόγραμμα:

```bash
java HW4_Team50.SimilarityTest <sentences_file> <training_file1> <training_file2> ...
```

Παράδειγμα:

```bash
java HW4_Team50.SimilarityTest sentences brown-train-sentences pg2600 pg7178
```

- Το πρώτο όρισμα είναι το αρχείο με τις ερωτήσεις (`sentences.txt`).
- Τα επόμενα είναι τα training αρχεία (χωρίς το `.txt`).
- Όλα τα `.txt` αρχεία πρέπει να βρίσκονται μέσα στο φάκελο `HW4_Team50`.

---

## Πληροφορίες Υλοποίησης

- Οι προτάσεις διαχωρίζονται με τελείες, ερωτηματικά ή θαυμαστικά.
- Γίνεται καθαρισμός κειμένου: αφαίρεση stopwords και μη αλφαβητικών χαρακτήρων.
- Οι σημασιολογικοί περιγραφείς αποθηκεύουν συχνούς "γείτονες" λέξεων σε HashMap.
- Υπολογισμός similarity με βάση cosine similarity.
- Οι απαντήσεις και το ποσοστό επιτυχίας γράφονται σε αρχείο `accuracy.txt`.
